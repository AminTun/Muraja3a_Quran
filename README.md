# How It Works

This app helps you create a smart daily revision schedule for the portions of the Quran you have memorized.


The app allows you to:


Select the portions you want to include in your revision schedule.

Set your daily revision pace (one quarter or more).

Record each daily revision session and indicate your memorization level.

Use a smart revision feature that automatically generates a schedule based on the memorization level of each portion, determining how frequently each portion should be reviewed.


This feature gives higher priority to the portions that are less well memorized. Each quarter is scheduled according to its memorization level.


The memorization level is determined when the user records the completion of a quarter for the first time. Initially, all selected portions have the same memorization level.


There are five memorization levels:


Excellent memorization — Very low revision priority

Good memorization — Low revision priority

Average memorization — Medium revision priority

Basic memorization — Normal revision priority

Newly memorized — High revision priority


Example:

If the revision group consists of:


Quarter 1 — Excellent memorization

Quarter 2 — Average memorization

Quarter 3 — Newly memorized


The resulting revision schedule would be:


Quarter 3 → Quarter 2 → Quarter 3 → Quarter 2 → Quarter 1 → Quarter 3 → …
